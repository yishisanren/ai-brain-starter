# 月度归纳模式（每月 1 日 12:30，含季度附加与修剪执行）

读取：上月全部 `_meta/weekly/*`、各项目全部长期文件、`lessons/*`、`user/PREFERENCES.md`、`_meta/PENDING.md`、`_meta/runs/*`、`skills/REGISTRY.md`、上一份 `_meta/monthly/*`。

输出：`_meta/monthly/<YYYY-MM>.md`；把「给你的一页」作为最终回复，写在定时任务会话里。

## 文件结构

```markdown
---
title: 月度归纳 <YYYY-MM>
generated: <时间>
---
# 月度归纳 · <YYYY-MM>

## 给你的一页
1. 这个月做成了什么：每个项目的真实成果；项目状态变化（新建、完成、转 paused）。
2. 漏了什么：跨周反复的模式；仍在漏的；补上了的。
3. 做对的事：本月被结果验证有效的决策与经验，各一句。
4. 上月预测 vs 现实：上月假设的回填结果；对了几条、错了几条；错的按归因三分类列出。
5. 下月唯一聚焦：只选一件事。
6. 经验沉淀：新增经验数；升为已验证的；转需复核的；升格为 Skill 草案的；Skill 反馈。
7. 记忆库体检：
   - 膨胀：STATUS 超限的项目；LESSONS 条数最多的项目；inbox 未处理文件数。
   - 记忆质量：日结执行率（有日结天数 / 有会话天数，按机器与 agent）；「更正」带根因的比例；「假设」带到期日的比例。
   - 外部输入吸收：_unsorted 未归类条目数。
   - 意图追踪：「下一步」超过 30 天没变的项目。
   - 节律健康：日汇总、周总结按时运行次数与失败次数。
   - 待裁定修复率：上月 D 项已处理 / 总数；≥80% 正常；<50% 单列「还欠 N 件」。
   - 承诺检查：汇总说要做的（草案、修剪、通知）做到了吗。
   - 一致性：同一项目在 STATUS、DECISIONS、LESSONS 里互相矛盾的表述。
8. 修剪建议（不执行，等回复「修剪 全部」或编号）：
   - 同项目内本质相同的经验：建议合并，保留被合并 id 作别名。
   - 6 个月未被任何条目引用的经验：建议归档为「历史经验」。
   - paused 满 90 天的项目：建议 done（30 天转 paused 已由日汇总自动做）。
   - 待裁定超过 14 天：建议关闭或再提醒。
   - 假设过期未回填：建议标过期。
   - 项目数超过 20，或单个项目经验超过 40 条：建议拆分或合并。
9. 生长快照：项目数、经验数、已验证经验数、Skill 数、偏差档案数；本月新增与修剪；与上月对比。
10. 偏好校准：待确认偏好；行为与已确认偏好冲突的实例。
11. 一句话：本月最该记住的一件事。

## 明细
（每个项目一节：本月做了、决定、假设回填、经验、偏差）
```

## 季度附加（3、6、9、12 月）

1. 记忆一致性抽查：随机抽 10 条 3 个月前的经验或决定，逐条检查是否仍被 STATUS、DECISIONS 一致引用，是否已被更正却未标记，是否与后来的结果矛盾。报告「抽查 10 条，一致 X 条，失效未标 Y 条，已修正」，并当场修正标记。
2. 季度信：这一季做成了什么、变化最大的项目、最值得保留的三条经验、下一季建议聚焦。
3. 12 月的月度归纳加一节「这一年」，串起四封季度信。

## 修剪执行

执行前的三条复验纪律（修剪清单是生成时的快照，逐项核当前态再动，不照单全标）：

- 假设 id `H-<日期>-<序号>` 历史上曾跨项目重号：标过期前逐条定位到具体项目的 HYPOTHESES.md 并核对该行到期日，到期日未过的不标，并在给用户的回执里说明例外。
- 项目标 done 前核 STATUS 与 INDEX 的目标 / 现状确实已闭环（验收记录在条目里），未闭环的不改并在回执列出原因。
- 每次文本替换后回读目标行验证生效：模式不匹配时替换会静默返回原文，必须记录每一项的变更结果（改了 / 没匹配到 / 无变化），没匹配到的改用精确整行文本重试一次。

用户回复「修剪 全部」或「修剪 1,3」后执行对应编号：

- 合并经验：保留一条为主，被合并 id 写进主条目的「别名」，原条目状态「已合并到 <id>」。
- 归档：条目移入 `projects/<id>/history/archive.md` 或 `lessons/archive.md`，原位置留一行指针。
- 项目改 paused 或 done：只改 INDEX 与 STATUS 的状态。
- 原则：不删除；优先合并；归档代替删除；失败经验保留；每项操作写进 `_meta/runs/<今天>.md`，可逆。
